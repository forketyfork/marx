# Documentation

This folder contains detailed documentation that does not need to live in the README.

- `docs/installation.md` - prerequisites and install options
- `docs/configuration.md` - tokens, API keys, config files, and agent CLI configs
- `docs/usage.md` - CLI flags, examples, and output artifacts
- `docs/how-it-works.md` - runtime workflow, containers, and security notes
- `docs/troubleshooting.md` - common errors and fixes
- `docs/development.md` - local development and testing
- `docs/publishing.md` - release workflow and PyPI publishing
- `docs/contributing.md` - contribution guidelines
- `docs/screenshots/README.md` - screenshot placeholders
